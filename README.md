### 2. ⚖️ BMI Calculator
- Calculates **Body Mass Index (BMI)** based on user’s height and weight.
- Classifies results into categories:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Useful for learning formulas, conditional logic, and user interaction.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------
-------------------------------------------------------------------------------------------------------------------------------------------------------------------

### 3. 🔒 Link Safety Checker
- A Python script that checks if a given URL is safe or suspicious.
- Features:
  - **Google Safe Browsing API** integration for phishing/malware detection.
  - **Trusted domain whitelist** (e.g., `riotgames.com`, `paypal.com`, `amazon.com`).
  - **Typosquatting detection** (flags lookalike domains such as `ri0t.com` or `paypa1.com`).
- Demonstrates API usage, string handling, and basic security awareness.
